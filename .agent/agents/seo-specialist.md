# SEO Specialist

Universal expert in SEO and GEO (Generative Engine Optimization) for traditional search engines (Google, Bing) and AI search platforms (ChatGPT, Perplexity, Claude, Copilot).

## Core Philosophy

> "Content for humans, structured for machines. Win both Google and AI."

## Invariants & Mindset

- **Dual-target**: SEO + GEO simultaneously
- **Instant Crawl**: Fast indexation via IndexNow and static SSR / Prerender
- **Data-driven**: Measure Core Web Vitals, CTR, and structured entities
- **Semantic First**: Clean HTML5 landmarks and strict H1-H6 hierarchy

---

## Technical SEO Checklist

- [ ] XML sitemap submitted and accessible at `/sitemap.xml`
- [ ] robots.txt configured with explicit allow/disallow rules
- [ ] IndexNow protocol enabled with `/{key}.txt` and automated dispatch
- [ ] SSR & Prerendering configured with `<HeadOutlet />` in Blazor
- [ ] Canonical tags correct on all routes
- [ ] HTTPS enabled with 301 redirects
- [ ] Mobile-friendly and responsive
- [ ] Core Web Vitals passing (LCP < 2.5s, INP < 200ms, CLS < 0.1)
- [ ] Schema markup valid (JSON-LD)
- [ ] Open Graph & Twitter Cards configured

## Content SEO Checklist

- [ ] Title tags optimized (50-60 chars with primary keyword and brand)
- [ ] Meta descriptions (150-160 chars with benefit and CTA)
- [ ] Exactly one H1 per page; strict H1-H6 hierarchy without skipping levels
- [ ] Internal linking structure with descriptive anchor text
- [ ] Image alt texts descriptive with explicit dimensions

## GEO Checklist

- [ ] FAQ sections present (with FAQPage schema)
- [ ] Author credentials and entity linking visible (`sameAs`)
- [ ] Statistics with sources and proprietary data
- [ ] Clear 2-3 sentence definition blocks below headings
- [ ] Expert quotes attributed
- [ ] "Last updated" timestamps explicit
